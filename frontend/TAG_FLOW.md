# 낱말 태그 선택 흐름

1. 기분 선택
2. 태그 선택: 무엇을 최대 3개, 어디서 최대 1개, 누구와 최대 2개. 기본·커스텀 태그를 합산한다. 날씨는 생략할 수 있고 최대 1개를 선택한다.
3. 그림으로 남길 활동 선택: 앞에서 고른 무엇을 중 하나를 반드시 직접 선택한다. 후보가 하나여도 자동 선택하지 않는다. 장소·동행·날씨는 이전 선택을 고정해서 보여 준다.
4. 그림 생성 후 한 줄 작성·기록 저장

무엇을·어디서·누구와 섹션에서 각각 낱말 커스텀 태그를 추가·삭제한다. 별도의 내 태그 영역이나 아이콘 선택 기능은 없다. 같은 이름이라도 카테고리가 다르면 별도 태그다.

## 기록 태그와 그림 태그

- `DiaryEntry.tags`: 일기에 선택했던 태그 전체의 스냅샷.
- `DiaryEntry.imageTags`: 대표 활동 하나와 선택한 장소·동행·날씨의 스냅샷.
- `DiaryDraft.mainActivityId`: 활동 선택 화면에서 명시적으로 고른 후보 ID. 해당 태그를 선택 해제하거나 삭제하면 비워진다.
- 그림 요청의 `activities`에는 대표 기본 활동 코드 하나만 들어간다. 대표 활동이 커스텀이면 기본 활동 코드는 비우고 해당 커스텀 ID를 사용한다. 선택하지 않은 커스텀 활동 ID는 요청에 넣지 않는다.
- 커스텀 장소·동행도 그림 요청에 포함하되 선택한 카테고리 정보를 태그 목록과 스냅샷에 유지한다.
- 같은 내용의 요청 재전송은 기존 요청 키를 유지한다. 다른 활동을 선택하면 새 요청 키를 사용한다.
- 재시도는 같은 그림 태그와 장착 모찌를 유지한다. 다시 작성하기는 태그 전체를 복원한 뒤 활동을 다시 고르게 한다.

현재 일기·태그 저장과 이미지 생성은 기존 Mock 경계에서 동작한다. 이번 작업은 서버 API 연동을 추가하지 않는다. 과거 기록에 `imageTags`가 없으면 기존 태그 표시를 사용한다.
