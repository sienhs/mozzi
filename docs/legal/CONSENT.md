# 가입·AI 생성 안내 및 동의 문구

내부 구현용 초안 / 작성일: 2026-10-27

아래 문구는 화면에 사용할 초안입니다. `[공개 전 확정]` 항목을 채우고 개인정보 처리방침과 실제 데이터 흐름이 일치하는지 확인한 뒤 적용합니다. 체크박스를 많이 넣는 것이 목적은 아닙니다. 실제로 동의가 필요한 처리를 구분합니다.

## 1. 로그인 전 이용 나이 확인

```text
오늘의 모찌는 만 14세 이상부터 이용할 수 있어요.
이용 나이를 확인해 주세요.

[나이 확인]
```

만 14세 미만이면 다음 안내 후 가입을 중단합니다.

```text
지금은 만 14세 이상만 가입할 수 있어요.
입력한 내용은 가입 정보로 저장하지 않아요.
```

마지막 문장은 실제로 미가입 입력을 저장하지 않는 구현에서만 사용합니다. 생년월일 수집 또는 연령 확인 결과만 저장할지 결정하고, 서버 검사 및 보관 정책도 맞춥니다. 체크박스 하나만으로 모든 연령 확인 의무가 충족된다고 가정하지 않습니다.

## 2. 가입 화면

```text
모찌를 시작하기 전에 확인해 주세요.

□ [필수] 이용약관에 동의해요.                 [전문 보기]
□ [필수·적용 여부 확인] 개인정보 수집·이용에 동의해요. [상세 보기]

개인정보 처리방침 보기

[가입하기]
```

`필수·적용 여부 확인`은 개발 표시이며 사용자 화면에 그대로 노출하지 않습니다. 계약 이행 등 다른 적법한 근거로 처리하는 항목과 동의를 근거로 처리하는 항목을 확정하여 실제 체크박스를 구성합니다. 개인정보 처리방침을 읽는 링크와 수집·이용 동의는 별개입니다. 마케팅·광고·푸시 수신 동의는 만들지 않습니다.

### 수집·이용 동의를 사용하는 경우의 상세 문구

| 항목 | 안내 |
| --- | --- |
| 목적 | 회원 식별·계정 관리, 일기 기록 보관 및 회원이 요청한 기능 제공 중 동의로 처리하는 목적: [공개 전 확정] |
| 정보 | 이메일·Google 계정 고유 식별자, 일기·감정·활동 등 동의를 근거로 실제 처리할 항목: [공개 전 확정] |
| 보유 기간 | 탈퇴·일기 삭제·목적 달성 시까지 등 실제 항목별 기간: [공개 전 확정] |
| 거부권·영향 | 동의를 거부할 수 있습니다. 거부하면 제한되는 기능을 필요한 범위에서 구체적으로 안내합니다: [공개 전 확정] |

모든 선택 정보를 필수로 묶지 않습니다. 법령상 별도 동의가 필요한 정보 처리가 생기면 구분하여 안내합니다. 자유 입력의 일기에 민감한 내용이 들어갈 가능성이 있으므로 입력 최소화·전송 전 제거 등 처리 방침을 출시 전에 검토합니다.

## 3. 첫 AI 생성 전 눈에 띄는 안내

```text
일기로 모찌 그림과 영상을 만들어요.

생성을 요청하면 작성한 일기 전체와 생성에 필요한 입력이
Atlas Cloud 및 실제 모델 처리업체에 전달돼요.
일기에는 이름·연락처 등 불필요한 개인정보를 적지 마세요.

그림: GPT Image 2.5 Sunburst
영상: Veo 3.1

[전송 정보와 보관 기간 보기]
[취소] [확인하고 생성하기]
```

이 화면은 인공지능기본법 제31조의 생성형 AI 사전 고지도 겸합니다. 생성형 AI를 쓴다는 사실은 첫 생성 전뿐 아니라 스토어 설명이나 생성 화면 등에서도 알 수 있도록 합니다.

### 생성 결과 표시

그림·영상을 보여 주는 모든 화면(일기 상세, 캘린더, 뽑기 결과, 다운로드·공유 시 포함)에 AI 생성물임을 표시합니다.

```text
AI로 생성된 그림이에요
AI로 생성된 영상이에요
```

다운로드·외부 공유 기능을 제공한다면 앱 밖에서도 알아볼 수 있도록 이미지·영상 자체에 표시(문구·워터마크) 또는 메타데이터를 남기는 방법을 함께 정합니다. 모델이 넣는 SynthID·C2PA 등이 실제로 유지되는지는 확인 후 판단합니다.

이 화면은 외부 처리를 알리는 설명입니다. 법적 동의를 별도로 받아야 하는 경우에는 아래 상세 내용과 구분된 동의를 추가합니다. 단순히 ‘확인하고 생성하기’를 누른 것만으로 모든 국외 이전 동의를 대체했다고 처리하지 않습니다.

- 이전받는 자 및 연락처: [공개 전 확정]
- 이전 국가: [공개 전 확정]
- 이전 항목: 일기 전체 및 실제 생성 입력·결과 [공개 전 확정]
- 시기·방법: 생성 요청 시 HTTPS API 전송 [실제 연동 확인]
- 목적: 요청한 그림·영상 생성
- 보유·이용 기간: 업체·모델별 [공개 전 확정]
- 거부·철회 방법 및 영향: [공개 전 확정]

```text
□ 위 내용을 확인했고 개인정보의 국외 이전에 동의해요.
```

계약 이행에 필요한 처리위탁·보관의 공개·고지 등 다른 적법한 근거를 적용한다면 그 근거에 맞게 구성합니다. 근거와 계약이 미정인 채로 전송을 시작하지 않습니다.

## 4. 탈퇴 확인 창

```text
모찌에서 탈퇴할까요?

탈퇴하면 계정 이용이 중단되고 회원 정보, 일기,
그림·영상 등 연결된 데이터가 삭제돼요.
삭제가 끝난 기록은 복구할 수 없어요.
개인을 알아볼 수 없는 전체 합계 통계는 남을 수 있어요.

[삭제 일정·백업 안내 보기]
[취소] [탈퇴하고 삭제 요청]
```

삭제 작업이 끝나기 전에는 ‘모든 데이터 삭제 완료’라고 표시하지 않습니다. 접수·처리 중·완료를 실제 상태에 맞춰 안내합니다.

## 5. 서버에서 관리할 내용

- 필수 동의 누락과 만 14세 미만 가입을 서버에서도 검사
- 동의 항목·버전·서버 기준 시각·회원 식별 정보와 해당 전문 버전 관리
- 국외 이전 동의가 있다면 일반 약관 동의와 구분하고 철회 경로 제공
- 선택 동의를 거절해도 무관한 기능 이용 가능
- 로그에 토큰·일기 원문·동의 요청 전체를 불필요하게 출력하지 않음
