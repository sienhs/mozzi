#   2) uv pip install --python .venv\Scripts\python.exe torch==2.13.0 torchvision==0.28.0 torchaudio==2.11.0 --index-url https://download.pytorch.org/whl/cu130
#   3) uv pip install --python .venv\Scripts\python.exe -r third_party\ai-toolkit\requirements.txt
#   4) uv pip install --python .venv\Scripts\python.exe -r requirements.txt
#
# 2)·3) 은 ai-toolkit 이 고정한 버전이다 (torch 2.13.0 cu130, diffusers git c943837, transformers 5.5.3,
